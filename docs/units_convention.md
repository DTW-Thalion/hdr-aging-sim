## 1. The two candidate conventions

Write the fast-subsystem state as a vector of standardised departures from the
youthful set-point, `x ∈ ℝⁿ`, with `D = diag(1/τ_i)` from
`data/tau_registry.json`.

### Convention R — rates

`J_ij` carries units of d⁻¹ and enters the dynamics additively:

```
ẋ = A x ,      A = −D + J ,      [J_ij] = d⁻¹
```

The steady-state gain implied by a single entry is `τ_i · J_ij` (dimensionless).
The two-axis bifurcation condition is

```
J_IM · J_MI  >  1 / (τ_I τ_M)                                            (R1)
```

and in general the system loses stability when `α(A) = max Re λ(A) ≥ 0`.  Both
conditions are τ-dependent: the same coupling matrix is stable or unstable
according to the recovery timescales.

### Convention G — gains

`g_ij` is dimensionless, the steady-state SD-displacement of target `i` per
sustained unit SD-displacement of source `j`.  It enters through the damping:

```
J_ij = g_ij / τ_i ,  i.e.  J = D G ,  so   ẋ = −D(I − G) x               (G0)
```

The two-axis condition and the general condition are

```
g_IM · g_MI  >  1                                                        (G1)
ρ(G_fast)    ≥  1                                                        (G2)
```

where `ρ(·)` is the spectral radius.  For a non-negative `G` (which is what the
matrix becomes once the protective entries move to κ —
`docs/protective_coupling_formulation.md`), `A = −D(I − G)` is Hurwitz **iff**
`ρ(G) < 1`, by Perron–Frobenius: the Perron root of `G` is real and dominant, so
`det(I − G) > 0` with all leading principal minors positive exactly when
`ρ(G) < 1`, and `D` is positive diagonal, which preserves the sign structure
without moving the stability boundary.  Conditions (G1) and (G2) are
**τ-free**.  Timescales set how fast the system traverses a basin; they do not
set whether the basin is stable.

The two conventions are not notational variants.  They assert different physics
for the same compiled numbers.  Under R the T2D bifurcation is τ-driven: the
loop closes because recovery slows with age.  Under G it is loop-gain-driven:
the loop closes because the basin changes `G`, at any age.

## 2. Evidence

### 2.1 The compiled numbers are internally inconsistent under R

`HDR-mechanistic/results/units_evidence_package.md` §2 computes `τ_i · J_ij` for
every numerically compiled entry using the framework registry.  **10 of 42**
numeric entries imply a healthy-basin steady-state gain greater than 1, i.e. a
sustained 1-SD displacement of the source would move the target by more than
1 SD.  The pattern is monotone in `τ_target`: median implied gain at age 25 is
0.01 for M and 0.00 for N (fast targets), 0.70 for I and 0.66 for C, and **52.50
for E and 16.88 for B**.  The E row reaches 440 SD/SD at age 80 (`J_E_I`,
`J_E_M`); the B row reaches 112.50 (`J_N_B`).

A steady-state gain of 440 is not a strong coupling, it is a unit error.  Under
G the same compiled numbers are bounded by construction and the E and B rows
read as 0.10–0.25 SD/SD.

### 2.2 The pipeline that produced the magnitudes already denominates them as gains

`HDR-mechanistic/data/inputs/effect_size_bounds.json` declares its tiers in
**SD target per SD source**: strong ≥ 0.5, moderate 0.2–0.5, weak 0.05–0.2.  Its
quantitative anchor is `J_I_M = 0.4–0.8 SD HOMA-IR per SD TNF-α` from the
anti-TNF meta-analysis.  `units_evidence_package.md` §3 lines the pipeline's
quantitative gains up against both readings of the compiled value:

| Entry | pipeline gain | compiled disease value read as a gain | R-implied gain | R overshoot |
|---|---|---|---|---|
| `J_M_I` | 0.4–0.8 | 0.50 | 8.50 | 14.2× |
| `J_mito_I` | 0.2–0.6 | 0.40 | 6.80 | 17.0× |
| `J_I_M` | 0.4–0.8 | 0.42 | 0.09 | 0.15× |
| `J_mito_E` | 0.1–0.2 | 0.20 | 400.00 | 2670× |
| `J_I_B` | 0.1–0.3 | 0.25 | 62.50 | 313× |
| `J_N_B` | 0.6–1.0 | 0.45 | 112.50 | 141× |

Read as gains, the compiled disease values sit inside or beside the pipeline's
independently derived ranges for most entries.  Read as rates, they overshoot by
12–17× on the I row and by 140–2700× on the B and E rows.  The simulation is
reading, as per-day rates, numbers that the pipeline wrote as dimensionless
gains.  **The inconsistency is between the repositories, not inside either.**

### 2.3 The cross-lagged data now discriminates, and it discriminates by a bound

This is new since the evidence package.  `results/lead_lag_phi_table.json`
(deliverable D) reports, for every ordered pair, the autoregressive coefficient
`φ_jj` of the target that the published scripts estimated but never exported.
The specification in `scripts/elsa_lead_lag.py` and
`scripts/inchianti_lead_lag.py` is

```
Δx_target = β·x_source(t) + γ·x_target(t) + δ·age + const
```

so `x_target(t+1) = (1+γ)·x_target(t) + β·x_source(t) + …`, giving
`φ_jj = 1 + γ` and an implied steady-state gain of `β/(1−φ_jj) = −β/γ`.  The
evidence package could only bracket this over assumed φ; it is now a point
estimate with a standard error.

For the significant pairs whose compiled entry is numeric:

| Model | Pair | β | φ_jj | empirical gain (SE) | compiled as gain (h→d) | R-implied gain (25→80) |
|---|---|---|---|---|---|---|
| ELSA | I→M | +0.0646 | 0.863 | **0.471** (0.049) | 0.18 → 0.42 | 0.01 → 0.09 |
| InCHIANTI 4-axis | I→M | +0.0328 | 0.758 | 0.135 (0.062) | 0.18 → 0.42 | 0.01 → 0.09 |
| InCHIANTI 5-axis | **I→B** | +0.1144 | 0.549 | **0.254** (0.087) | 0.10 → 0.25 | **13.5 → 62.5** |
| InCHIANTI 5-axis | **F→B** | +0.0240 | 0.553 | **0.054** (0.018) | −0.30 → −0.18 | **−40.5 → −45.0** |
| ELSA | M→I | +0.0276 | 0.603 | 0.069 (0.017) | 0.25 → 0.50 | 1.00 → 8.50 |
| ELSA | I→F | +0.0137 | 0.809 | 0.072 (0.025) | 0.25 → 0.50 | 0.50 → 1.75 |
| ELSA / InCHIANTI | F→I | +0.0251 / +0.0143 | 0.610 / 0.337 | 0.064 / 0.022 | −0.35 → −0.25 | −1.40 → −4.25 |

The decisive rows are the B-axis pairs, because they are the only directly
measured pairs where the two readings differ by orders of magnitude.  `I→B` has
an empirical steady-state gain of 0.254 ± 0.087; the compiled disease value read
as a gain is 0.25.  The rate reading requires 13.5–62.5 — between 50× and 250×
the measured value, and outside what any standardised regression can produce.
`F→B` gives 0.054 ± 0.018 against a rate-implied 40–45, an 800× discrepancy.

The argument is a **bound**, not a point identification, and it should be stated
that way.  Because `|β| ≤ 1` for standardised variables and `φ_jj < 1`, a
long-run gain of 440 would require `φ_jj ≥ 1 − 1/440 = 0.9977`.  The largest
`φ_jj` anywhere in the table is 0.941 (`model inchianti_5axis_IMNFB`, target F),
and the E and B rows' targets sit at 0.549–0.560.  **No admissible φ makes the
rate reading of the quasi-static rows compatible with the measured co-movement.
Every compiled value read as a gain is admissible.**

### 2.4 τ cannot rescue the rate reading

`units_evidence_package.md` §5 showed that the published anchor
`α_fast(25) = −0.19 d⁻¹` is unreachable under either repository's τ without
stabilising coupling, because `τ_C = 6 d` bounds the uncoupled abscissa at
−0.167.  With the unified registry (`data/tau_registry.json`, deliverable B),
`α_uncoupled(25) = −0.1667` and `α_fast(25, healthy) = −0.1889` at the published
`c = 0.89`.  The published margin is therefore *produced by* the negative F row
— the model is stable at age 25 only because the protective entries are read as
stabilising feedback.  That is the subject of
`docs/protective_coupling_formulation.md`, and it is a second, independent
reason the rate reading is load-bearing in a way it should not be.

## 3. Evidence against the adopted convention

This section is not a formality.  Three things cut against Convention G, and two
of them are not resolved by adopting it.

**(a) The best-measured pair does not discriminate, and the two cohorts disagree
with each other.**  `I→M` is the paper's strongest empirical result
(ELSA p = 3.2 × 10⁻²⁰).  Its empirical long-run gain is 0.471 in ELSA but 0.135
in InCHIANTI — a 3.5× disagreement between cohorts on the same ordered pair,
larger than the gap between the two conventions for this pair.  The compiled
disease value read as a gain (0.42) is close to ELSA and 3× above InCHIANTI; the
rate-implied gain (0.09) is 5× below ELSA and within a factor of 1.5 of
InCHIANTI.  Taken alone, `I→M` is at best weak evidence for G and arguably mild
evidence for R.  The case for G rests on the slow-target rows, not on this one.

**(b) φ at a 3-year interval is not the fast subsystem's relaxation, so
`β/(1−φ)` is not a clean estimate of `g_ij`.**  If the fast axes really relax
with τ of 0.003–6 d, then over a 3-year sampling interval the discrete
transition matrix `exp(AΔt)` is numerically zero and both β and φ should be ≈ 0.
The observed `φ_jj` of 0.34–0.94 therefore cannot come from the OU dynamics; it
comes from stable between-person differences that within-person differencing
does not remove.  `results/lead_lag_concordance_audit.md` reached the same
conclusion from the other direction, rejecting the Φ-matrix concordance
convention because "Phi entries approach zero" at this interval.  What
`β/(1−φ)` measures is the steady-state gain *of whatever process carries the
3-year persistence*, which blends the regulatory loop with slow co-drift.  This
is why §2.3 is framed as a bound: the bound (`no φ < 1 can produce a gain of
440`) survives this objection, because it only needs `φ_jj < 1`.  A point
comparison between 0.254 and 0.25 does not survive it and should not be quoted
as a validation of the compiled magnitude.

**(c) Adopting G says nothing about whether the compiled magnitudes are
right, and the data cannot yet settle it.**  Comparing each significant
cross-lagged pair's empirical steady-state gain against the midpoint of its
compiled value read as a gain gives, with protective sources excluded (their
compiled values move to κ and are no longer gains, so including them compares
two different quantities):

| Pair | empirical gain | compiled midpoint | ratio |
|---|---|---|---|
| I→M (InCHIANTI 4-axis) | 0.136 | 0.300 | 2.21 |
| I→M (InCHIANTI 5-axis) | 0.133 | 0.300 | 2.25 |
| I→B (InCHIANTI 5-axis) | 0.254 | 0.175 | 0.69 |
| I→M (ELSA) | 0.471 | 0.300 | 0.64 |
| I→F (ELSA) | 0.072 | 0.375 | 5.22 |
| M→I (ELSA) | 0.070 | 0.375 | 5.40 |

Geometric-mean ratio **1.99, 95% CI [0.75, 5.31]**, log-ratio SD 0.935 (a
multiplicative spread of ×2.55), n = 6, one-sample t on the log ratio
**p = 0.132** (`results/units_convention_numerics.json`, key
`scale_diagnostic`).

So the compiled tiers are *not* demonstrably biased — but they are only pinned
to within roughly a factor of 2 either way, on six usable pairs, and the point
estimate sits at 2×.  The consequence is sharper than a bias claim:

- the **level** of `G` is essentially unidentified by the data we have. The
  scale uncertainty (CI spanning 0.75–5.31) is an order of magnitude wider than
  the Monte Carlo band in §5, which only propagates the per-entry confidence
  grades and implicitly assumes the level is right;
- the **structure** is better supported than the level: the ordering
  healthy < pre-disease < disease is driven by the tier→basin map, not by the
  absolute values, and survives any global rescaling;
- therefore `ρ(G_pre-disease) ≈ 0.97` must not be reported as evidence that the
  pre-disease basin sits at the edge of stability. The distance of that number
  from 1 is smaller than the scale uncertainty on `G` itself. See §5.

Task 1.3 should either estimate a single global scale on `G` from these pairs —
one parameter from six anchors is tractable, and preserves the tier structure
while fixing the level — or carry the scale explicitly as a nuisance parameter
and report `ρ` as a distribution over it. It should not treat the compiled
values as measurements.

**(d) A smaller point, recorded for completeness.** Under G the magnitude tier
loses its only τ-dependent content, so the tier→value map in
`src/hdr_sim/csv_loader.py` (`TIER_DEFAULTS`) now has to be re-derived against
`effect_size_bounds.json` rather than inherited.  Work, not an objection.

## 4. Decision

**Adopt Convention G.  The canonical compiled object is a dimensionless
steady-state gain matrix `G`, with `g_ij` in SD target per SD source.  Rates are
derived, never stored: `J = D G`, `J_ij = g_ij / τ_i`.**

Rationale in one line per claim, each with its source:

1. The pipeline that produced the magnitudes declares them as gains
   (`HDR-mechanistic/data/inputs/effect_size_bounds.json`, tiers ≥ 0.5 /
   0.2–0.5 / 0.05–0.2 SD per SD).
2. Read as rates, 10 of 42 numeric entries imply healthy-basin gains > 1 and the
   E row reaches 440 (`units_evidence_package.md` §2).
3. Read as rates, the compiled values overshoot the pipeline's own quantitative
   estimates by 12–17× (I row) and 140–2700× (B, E rows)
   (`units_evidence_package.md` §3).
4. No admissible autoregressive coefficient reconciles the rate reading of the
   quasi-static rows with the measured cross-lagged coefficients: a gain of 440
   needs φ ≥ 0.9977, and the largest φ observed is 0.941
   (`results/lead_lag_phi_table.json`).
5. The directly measured B-axis pairs land on the gain reading and are 50–800×
   from the rate reading (`I→B` 0.254 ± 0.087 vs 13.5–62.5; `F→B` 0.054 ± 0.018
   vs 40–45).

**Falsifiability.** The decision is falsified if a longitudinal design sampled at
or below the axis recovery timescales — the planned MIMIC-IV perturbation-recovery
analysis is the natural venue — recovers per-interval coefficients whose implied
steady-state gains for the slow-target rows are of order 10 or more.  It is also
falsified, more cheaply, if the B-axis `φ_jj` values prove to be artefacts of the
PTH proxy's wave-0–3 coverage; `results/lead_lag_phi_table.json` records N = 1629
and the realised interval (mean 3.11 y, SD 0.56) for that check.

## 5. What the decision implies for the aging-vs-disease framing

Under G the framework's two mechanisms separate cleanly, and the separation is
sharper than the manuscript currently states:

- **Aging is D-only within a fixed G.** Recovery timescales lengthen with age,
  so `D` shrinks and `α(A) = α(−D(I−G))` moves toward zero. But `ρ(G)` is
  unchanged, so the system does not cross the stability boundary with age alone.
  Ageing slows the return to the set-point; it does not open the basin.
- **Disease is a basin-dependent change in G.** Crossing `ρ(G) = 1` requires the
  coupling structure itself to change — the switched-system transition between
  basins.  This is what the compiled basin columns encode.
- The T2D claim in the main text must be restated.  Supplementary Note 2
  presently derives the bifurcation as `J_IM·J_MI > 1/(τ_I τ_M)`, which is
  condition (R1) and is τ-dependent.  Under G the condition is `g_IM·g_MI > 1`,
  which is τ-free.  The biological claim survives and arguably improves: T2D
  emerges when the bidirectional loop gain exceeds unity, a quantity that can be
  monitored without knowing anybody's recovery timescales.  The wording
  "exceeds the product of self-restoring capacities" becomes wrong and must go.

**On ρ(G_pre-disease).** From `results/units_convention_numerics.json`, the
compiled tiers give, for the 7-axis fast subsystem using numerically compiled
entries only (31 / 31 / 33 non-zero):

| Basin | ρ(G_fast) | ρ with the F row removed | Monte Carlo 95% | P(ρ ≥ 1) |
|---|---|---|---|---|
| healthy | 0.749 | 0.518 | [0.698, 0.858] | 0.000 |
| pre-disease | 0.969 | 0.753 | [0.903, 1.109] | 0.503 |
| disease | 1.311 | 1.127 | [1.227, 1.499] | 1.000 |

Monte Carlo: 20 000 draws, lognormal multiplicative noise with CV by confidence
grade (A 0.20, B 0.40, C 0.70), the specification already used in
`scripts/run_figure_uncertainty.py` for Supplementary Note 1.  Note what this
band does and does not cover: it propagates per-entry grade uncertainty around
the compiled values, holding their overall level fixed.

**This is a property of the compiled tiers, not a result.**  `ρ(pre-disease) =
0.969` is a restatement of the tier values and the tier→basin map; the 95% band
[0.903, 1.109] straddles unity and `P(ρ ≥ 1) = 0.50` is, precisely, a coin flip.
Taken with §3(c) — the level of `G` is pinned only to within a factor of ~2,
95% CI [0.75, 5.31], which is far wider than this band — the honest reading is
that the point estimate's proximity to 1 carries no information about where the
real pre-disease basin sits.  It must not be presented as confirmation that the pre-disease state is
near-critical, must not be used as a calibration target, and must not appear in
the manuscript as a finding.  What *is* reportable is the ordering and its
robustness: healthy is inside the boundary with P(ρ ≥ 1) = 0.000 and disease is
outside it with P(ρ ≥ 1) = 1.000, under the compiled uncertainty.

## 6. How the compiled CSV must be re-expressed

Executable spec for the J-matrix project.  Target file:
`data/J_matrix_compiled_9x9.csv`.  **Do not edit it before this document is
merged.**

### 6.1 Columns

Rename in place, no value changes:

| Current | New | Meaning |
|---|---|---|
| `J_healthy` | `g_healthy` | dimensionless gain, healthy basin |
| `J_pre_disease` | `g_pre_disease` | dimensionless gain, pre-disease basin |
| `J_disease` | `g_disease` | dimensionless gain, disease basin |

Keep unchanged: `axis_from`, `axis_to`, `sign`, `magnitude_tier`,
`confidence_grade`, `age_trajectory`, `pmid_primary`, `pmid_secondary`,
`evidence_type`, `mechanism_brief`, `biomarker_role_note`.

Add:

| Column | Values | Meaning |
|---|---|---|
| `units` | `SD_per_SD` | literal, every row |
| `channel` | `J` \| `kappa` | where the entry enters the dynamics |
| `regime_dependent` | `true` \| `false` | sign/magnitude changes across basins |

`channel = kappa` for the 11 entries enumerated in
`docs/protective_coupling_formulation.md` §3 (8 F-row, plus B→I, B→M, B→N).
`regime_dependent = true` for `N→I`, `N→B`, `C→I`.

`axis_from` is the source, `axis_to` is the target; a row `(axis_from=M,
axis_to=I)` is `g_{I←M}`.  This matches `J_<source>_<target>` in HDR-mechanistic.
Do not change it, and do not transpose anything.

### 6.2 Values

1. **No numeric value changes in this step.** The re-expression is a declaration
   of units, not a recalibration. Recalibration is Task 1.3 and runs after this
   is merged.
2. Entries moving to `channel = kappa` keep their current negative sign in the
   CSV until the κ table replaces them; `docs/protective_coupling_formulation.md`
   §5 defines the tier→κ map. Loaders must skip `channel = kappa` rows when
   building `G`.
3. `qual_only` and `unknown` placeholders stay as they are.
4. Re-derive `TIER_DEFAULTS` in `src/hdr_sim/csv_loader.py` against
   `HDR-mechanistic/data/inputs/effect_size_bounds.json` (strong ≥ 0.5, moderate
   0.2–0.5, weak 0.05–0.2 SD per SD) rather than inheriting the current values.
   Flag, do not silently change, any compiled value that falls outside its own
   tier band after re-derivation.

### 6.3 Derived columns

**No derived column may be stored in the CSV.** Rates, implied gains and
basin-interpolated values are computed at load time, from `g_*` and
`data/tau_registry.json`, by script only:

```python
# src/hdr_sim/csv_loader.py
def G_basin(rows, basin, axes):          # dimensionless, channel == 'J' only
    ...
def J_from_G(G, tau):                    # J = D G, rates in d^-1
    return G / tau[:, None]
def A_from_G(G, tau):                    # A = -D (I - G)
    return -np.diag(1.0 / tau) @ (np.eye(len(tau)) - G)
```

Any script that needs `J` calls `J_from_G`.  No script constructs `A = -D + J`
from a stored rate.

### 6.4 Acceptance for the re-expression

- `G_basin` reproduces, from the re-expressed CSV, `ρ(G_fast)` = 0.749 /
  0.969 / 1.311 and 31 / 31 / 33 non-zero fast entries
  (`results/units_convention_numerics.json`, key `rho_G`).
- `A_from_G(G_healthy, tau(25))` and `-D + J_from_G(G_healthy, tau(25))` agree
  to machine precision.
- No column named `J_*` survives in the CSV.
- Every row has `units`, `channel` and `regime_dependent` populated.

## 7. What this does not settle

- The compiled magnitudes themselves (§3(c)). Task 1.3.
- τ_B and τ_E are turnover rather than perturbation-recovery timescales
  (`data/tau_registry.json`, `open_issues`). Neither enters the fast-subsystem
  margin, but neither can support a dynamical claim about its axis.
- The axis-I trajectory in `src/hdr_sim/csv_loader.py` overshoots its own
  declared 120-day anchor (48.60 d against 45.0 d). Phase 2.
- Whether the 3-year cross-lagged persistence can be decomposed into regulatory
  and between-person components at all. If it cannot, the gain calibration stays
  bounded rather than identified.

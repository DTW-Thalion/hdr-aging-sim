## 1. Adopted convention: **gains**

The canonical compiled object is a dimensionless steady-state gain matrix `G`.
`g_ij` = SD displacement of target `i` per sustained 1 SD displacement of source
`j`. Rates are derived, never stored:

```
J = D G ,   J_ij = g_ij / τ_i ,   A = −D(I − G) ,   D = diag(1/τ_i)
```

For non-negative `G`, `A` is Hurwitz **iff** `ρ(G) < 1`. Bifurcation conditions
in the adopted units:

```
two-axis:   g_IM · g_MI  >  1
general:    ρ(G_fast)    ≥  1
```

Both are **τ-free**. Aging is `D`-only within a fixed `G`; disease is a
basin-dependent change in `G`.

Decisive evidence: the quasi-static rows. Read as rates they imply steady-state
gains of 10–440 SD/SD, which would need an autoregressive coefficient
`φ ≥ 0.998`; the largest `φ` measured anywhere is 0.941. The directly measured
B-axis pairs land on the gain reading — `I→B` empirical long-run gain
0.254 ± 0.087 against a compiled-as-gain 0.25 and a rate-implied 13.5–62.5.

**Carry this caveat forward.** Adopting gains fixes the units; it says nothing
about the magnitudes. Comparing the six usable pairs (protective sources
excluded — their compiled values move to κ and are no longer gains) gives a
geometric-mean compiled/empirical ratio of **1.99, 95% CI [0.75, 5.31]**,
p = 0.132. The tiers are not demonstrably biased, but the *level* of `G` is
pinned only to within a factor of ~2 either way. That scale uncertainty is an
order of magnitude wider than the Monte Carlo band, which holds the level fixed.
The tier *structure* (the healthy < pre-disease < disease ordering) is better
supported than the level and survives any global rescaling.

## 3. CSV re-expression spec

`docs/units_convention.md` §6, executable. Summary:

- Rename `J_healthy` / `J_pre_disease` / `J_disease` → `g_healthy` /
  `g_pre_disease` / `g_disease`. **No value changes in this step.**
- Add `units` (`SD_per_SD`, every row), `channel` (`J` | `kappa`),
  `regime_dependent` (`true` | `false`).
- `axis_from` = source, `axis_to` = target. Unchanged. Do not transpose.
- **No derived column may be stored.** `J`, implied gains and basin
  interpolations are computed at load time by `G_basin` / `J_from_G` /
  `A_from_G` in `src/hdr_sim/csv_loader.py`.
- Re-derive `TIER_DEFAULTS` against `effect_size_bounds.json` (≥0.5 / 0.2–0.5 /
  0.05–0.2 SD per SD); flag, do not silently change, any compiled value outside
  its own tier band.
- Acceptance: `G_basin` reproduces ρ(G_fast) = 0.749 / 0.969 / 1.311 with
  31 / 31 / 33 non-zero fast entries; `A_from_G` and `−D + J_from_G` agree to
  machine precision; no `J_*` column survives.

## 4. Entries that move to κ

Eleven, all currently `sign = '-'`. Set `channel = kappa`; loaders skip them
when building `G`, which becomes all-positive.

**F row (8):** F→I (−0.35/−0.30/−0.25), F→M (−0.30/−0.25/−0.20),
F→E (−0.12/−0.10/−0.08), F→mito (−0.15/−0.12/−0.10), F→P (qual_only),
F→C (−0.12/−0.10/−0.08), F→N (−0.18/−0.15/−0.12), F→B (−0.30/−0.25/−0.18).

**B row (3):** B→I (qual_only), B→M (−0.10/−0.08/−0.05), B→N (qual_only).

**Regime-dependent (3), not κ:** N→I, N→B, C→I — set `g_healthy = 0`,
`regime_dependent = true`, pre-disease and disease unchanged.

κ identification rule (`docs/protective_coupling_formulation.md` §5):
`κ_is = ε_is / (1 − ε_is)` where `ε` is the interventional steady-state
fractional improvement from `effect_size_bounds.json`. Only F→I, F→M and F→B
have interventional or MR support and may take a numeric κ; the rest are
tier-derived and must be marked as such. Return as
`data/exports/kappa_table.json`.

## 5. Also fix while you are in there

`scripts/inchianti_lead_lag.py` defines `J_SIGNS` with comments written
(source, target) but consumes the keys (target, source), so the entry
`("N","I"): -1` is applied to the pair **I→N**, whose compiled value is +0.12.
`M→N` is affected the same way. This is why β(I→N) = −0.043 was recorded as
concordant. Delete `J_SIGNS` and read the predicted sign from the CSV — under
this convention it is `+1` for every `channel = J` entry.
